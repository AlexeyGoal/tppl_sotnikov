# Лексический анализатор

Программа на Python превращает исходный код в последовательность токенов.

## Запуск

```bash
python3 main.py <файл>
```

Пример:

```bash
python3 main.py input.txt
```

Для `x = y * 2 + z * 3` вывод:

```text
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
(OP, +, 1:11)
(IDENT, z, 1:13)
(OP, *, 1:15)
(INT, 3, 1:17)
```


При недопустимом символе или некорректном числовом литерале (например, `12abc`)
выводится ошибка и программа завершается с ненулевым кодом:

```text
<файл>:<строка>:<столбец>: lexical: <сообщение>
```

Например:

```text
input.txt:1:3: lexical: unexpected character '@'
```

## Тестирование

```bash
python3 -m pytest test_main.py
```
